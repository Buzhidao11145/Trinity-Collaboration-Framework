## 翻译规范

### 术语一致性

- 所有翻译**必须**参考 `i18n/glossary.md` 中的术语对照表
- 新出现的术语需添加到对照表并标注上下文
- 已有术语不得随意更改翻译

### 格式要求

- Markdown 格式、代码块、表格结构须与原文一致
- 英文文件命名：`文件名_EN.md`（`README_EN.md`、`core-principles_EN.md`）
- 其他语言文件命名：`文件名_LANG.md`（`README_JA.md` 为日文版）

### 内容同步

- 如果中文版本更新，对应翻译版本应在 **48 小时内** 同步
- 翻译版本在文件头标注同步日期和版本号

### 翻译风格

- 使用技术文档的标准句式，避免口语化表达
- 保持原文的章节结构和逻辑顺序
- 案例描述做适当调整以符合目标语言阅读习惯
- 代码块和命令行示例不翻译
- 使用中性语气，不添加原文没有的修饰或评价

## 贡献流程

```
1. Fork 本仓库
2. 创建分支：git checkout -b i18n/[language]
3. 创建翻译文件：i18n/README_[XX].md
4. 更新术语对照表（如有新术语）
5. 提交 PR
6. 在 PR 描述中注明：
   - 翻译的语言
   - 覆盖的文件范围
   - 翻译参考的原文版本
```
