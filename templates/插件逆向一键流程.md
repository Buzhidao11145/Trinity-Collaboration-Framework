## 一句话启动

```
龙虾，逆向分析这个插件来自<路径>，输出报告到<目标目录>
```

## 自动执行流程

### 1️⃣ 基础信息提取

| 检查项 | 命令 | 预期输出 |
|:-------|:-----|:---------|
| 文件类型 | `file <dylib>` | Mach-O 64-bit dynamically linked shared library |
| 架构 | `lipo -info <dylib>` | arm64 / arm64e |
| 外部符号 | `nm -gU <dylib> | head -50` | MSHookFunction等 |
| 库依赖 | `otool -L <dylib>` | CoreFoundation, UIKit等 |

### 2️⃣ 字符串分析

```bash
# 全部字符串导出
strings <dylib> > strings_raw.txt

# Hook关键词扫描
grep -i "MSHook\|logos\|substrate" strings_raw.txt

# 安全关键词扫描
grep -i "jail\|break\|detect\|bypass\|crack" strings_raw.txt

# URL/API端点
grep -i "http\|https\|api\." strings_raw.txt
```

### 3️⃣ class-dump（可选）

```bash
class-dump <dylib> 2>&1 || echo "class-dump失败，改用nm+strings"

# 替代方案：nm提取ObjC类
nm <dylib> | grep -i "OBJC_CLASS" | sed 's/.*_OBJC_CLASS_\$_//' | sort
```

### 4️⃣ 生成报告

按以下结构自动生成Markdown分析报告：

```markdown
# 插件分析报告：<插件名>

**分析时间：** YYYY-MM-DD HH:MM
**置信度：** 🟢高/🟡中/🔴低

## 基本信息
- 版本：X.Y
- 架构：arm64
- 大小：XXKB
- Bundle ID：com.xxx.xxx

## 功能分析
（通过字符串和符号推断的功能描述）

## Hook清单
| Hook目标 | 类型 | 目的 |
|:---------|:----|:-----|
| func/class/method | MSHookFunction/MSHookMessageEx | 猜测目的 |

## 安全发现
（文件操作、网络请求、持久化行为）

## 可借鉴代码模式
（值得引用的技术点）
```
