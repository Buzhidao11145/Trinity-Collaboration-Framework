## 自动执行流程

### 1️⃣ 侦察MTOP架构

```bash
# 在二进制/解压目录中搜索关键类
grep -r "MtopApiRequest\|MtopService\|MtopExt" <App目录>/
```

**结果判断：**
- ✅ 找到MtopApiRequest → MTOP架构，继续步骤2
- ❌ 未找到 → 非MTOP架构，给出5种替代方案

### 2️⃣ 定位sync()方法

```javascript
// 用Frida枚举ObjC类中的sync方法
// 保存为 locate_sync.js → 挂接到目标App

ObjC.classes['MtopApiRequest'].$ownMethods.forEach(function(m) {
    if (m.indexOf('sync') !== -1 || m.indexOf('Sync') !== -1) {
        console.log('[+] sync method found: ' + m);
    }
});
```

### 3️⃣ 编写代理脚本

```bash
# 选择合适的模板
cp ./proxies/template_proxy.js ./<App>_proxy.js
# 将默认类名替换为目标App的对应类名
```

### 4️⃣ 编写Python客户端

```python
from mtop_client_framework import MtopClientFramework

class <AppName>Client(MtopClientFramework):
    def __init__(self):
        super().__init__(
            app_name="<App名称>",
            proxy_script="proxies/<App>_proxy.js",
        )
```

### 5️⃣ 集成+测试

```bash
# 注册到统一框架
# 至少测试3个不同API端点
python3 test_framework.py --app=<App>
```

## 替代方案速查

| 非MTOP架构类型 | 推荐方案 | 参考 |
|:--------------|:--------|:-----|
| H5为主的App | WebView JS注入 | Playwright |
| 自定义协议 | NetworkExtension | 需越狱 |
| HTTPS API | MITM + 证书绑定绕过 | DaeGouTweak |
| NSURLSession原生 | Frida Hook原生网络库 | frida_utils.js |
| 仅有Web版 | Playwright浏览器自动化 | 爬虫管理平台 |
