# 即用型模板：知识库一键归档

> **触发语句：** "龙虾，把这些东西归档"
> **创建时间：** 2026-06-01
> **所属框架：** Trinity v1.0
> **标准化流程来源：** 知识库归档决策规则

---

## 一句话启动

```
龙虾，把<目标目录/路径>的内容归档
```

## 自动执行流程

### 1️⃣ 扫描新增内容

```bash
find <目标目录> -type f -not -path "*/.git/*" -not -name ".DS_Store" | sort
```

### 2️⃣ 按类型分类

| 文件后缀/名 | 分类 | 归档到 |
|:-----------|:----|:-------|
| `*.md` 含"报告、分析" | 📜 报告类 | 提取教训到 `learning/`，记录到 `tasks/` |
| `*.py` / `*.js` / `*.sh` | 🔧 脚本类 | 更新 `capabilities/` 工具清单 |
| `*文章*` / `*研究*` | 📝 文章类 | 更新 `capabilities/` 知识资产 |
| `*note*` / `learning_*` | 🧪 笔记类 | 补充到 `learning/学习成果记录.md` |
| `*失败*` / `*bug*` / `*error*` | 📕 失败记录 | 抽教训→`learning/`, 抽规则→`decisions/` |

### 3️⃣ 更新对应清单

- 报告类任务 → 补录到 `tasks/<项目名称>.md`
- 工具类能力 → 补录到 `capabilities/全局能力清单.md`
- 经验教训 → 补录到 `learning/学习成果记录.md`
- 决策规则 → 补录到 `decisions/决策知识库.md`

### 4️⃣ 更新指挥官简报

更新方法：
1. 修改"信息新鲜度报告"中文件的时间/大小
2. 在"近期完成任务"中新增一行
3. 更新"框架成长统计"数字

### 5️⃣ 输出归档结果

```
📋 归档完成报告
================
- 扫描目录：<路径>
- 新增文件：N个
- 归档到：tasks/N个 / capabilities/ / learning/ / decisions/
- 简报已更新：✅
```

## 产出物检查清单
